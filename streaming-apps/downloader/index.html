How to Install Downloader on Fire TV Stick

Updated September 5, 2026. By USAView Editorial Team. To install Downloader on Firestick, search for it in the Amazon Appstore, install it, then enable the required Developer Options permission. This guide covers each step and explains how to use Downloader to download an app on Fire TV.

Step 1: Install Downloader Step 2: Prep Your Firestick
About the app

What Is Downloader on Firestick?

Downloader is an app for Fire TV devices that lets you open a web address and download a file directly to the device. It is useful when an app or installation file is not available through the Amazon Appstore. After you install Downloader and grant it permission, you can enter a trusted URL or code, download the file, and follow the on-screen installation prompt.

Step 1

Install Downloader

Downloader is installed from the Amazon Appstore. Once it is on your Fire TV Stick, you can use its URL field to download compatible files. Start with the three steps below.

  1. Open Search

    From the Fire TV home screen, select Find, then choose Search.

  2. Type Downloader

    Type Downloader with the on-screen keyboard and select the matching suggestion when it appears.

  3. Select the App

    Open the Downloader listing, select Get or Download, and wait for the installation to finish. Select Open when ready.

Step 2

Prep Your Firestick

Fire TV may block installations from outside the Amazon Appstore by default. Enable the device setting for Downloader before attempting to install a downloaded app.

Allow "Apps from Unknown Sources"

Granting this permission will let you install apps you sideload via the Downloader app.

  1. Go to Settings

    From the Fire TV home screen, open Settings, then select My Fire TV.

  2. Developer Options

    Select Developer options if it is already visible.

  3. If Developer Options Are Hidden

    If Developer Options is not visible, select About and continue to the next step. If it is already visible, open it and continue below.

  4. Unlock Developer Options

    Select your Fire TV device name 7 times to unlock Developer Options.

  5. Confirmation Message

    After the seventh selection, look for a confirmation such as "Developer Options Enabled".

  6. Open Developer Options

    Return to the previous menu and select Developer options.

  7. Enable Installation

    On devices with a single toggle: select Apps from Unknown Sources and change it from Off to On.

    On devices with per-app permissions: open Install unknown apps, select Downloader, and turn it On.

Downloader is now ready to download compatible files. Only install apps from sources you trust and review a file's source before opening it.

After installation

How to Use Downloader After Installation

Once Downloader is installed and has permission to install unknown apps, the basic process is straightforward. Use a download address or code from a source you trust, and check that the file is intended for your Fire TV device before installing it.

  1. Open Downloader

    Open Downloader from your Fire TV apps or the Apps & Channels row. The first launch may ask for permission to access files; follow the on-screen prompt.

  2. Enter a URL or code

    Enter a trusted direct-download URL or short code in Downloader's URL field, then select Go. Check the address carefully before continuing.

  3. Download and install the file

    Wait for the download to finish. If an installation prompt appears, select Install; when it completes, choose Done to return to Downloader or Open to launch the app.

📺 Dedicated Streaming Devices & Sticks

Which Devices Work With Downloader?

Downloader is designed for TV devices and can be controlled with a compatible remote. The setup steps on this page focus on Amazon Fire TV devices; other Android TV devices may use different menus and permissions.

Amazon Fire TV Family

Every iteration including the Amazon Fire TV Stick, Fire TV Stick 4K, Fire TV Stick 4K Max, and the Fire TV Cube.

Google TV / Android TV Players

Popular retail units like the Google Chromecast with Google TV, Google TV Streamer, Nvidia Shield TV, Xiaomi Mi Box and other Android TV boxes.
